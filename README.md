# Learnify - Product Intern take-home

Reducing the lesson-3 drop-off with **Quests**: short, self-chosen learning goals with a reward the student picks upfront.

**Live prototype: https://learnify-quests.vercel.app** (nothing to install, takes ~2 minutes to click through)

## What's here

| File | What it is |
|---|---|
| `LEARNIFY_PRODUCT_CASE_STUDY.md` | The full case study (~7 min read) - problem, hypothesis, feature, AI reasoning, metrics, A/B test |
| `LEARNIFY_PRODUCT_CASE_STUDY.pdf` | 10-slide presentation version |
| `LEARNIFY_PRODUCT_CASE_STUDY.html` | Same deck as a web page, if that's easier to open |
| `prototype/` | Interactive React prototype - 6 clickable screens |

## Running the prototype

```
cd prototype
npm install
npm run dev
```

Open http://localhost:5173. Suggested path: complete the lesson → finish the quest → claim the reward → pick the next quest. The whole loop takes about two minutes to click through.
